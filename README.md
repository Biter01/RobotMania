# RobotMania

> 🚧 **Work in Progress** — currently in development. Expect bugs, missing features, and frequent changes.

A Doom-like, sprite-based 3D web shooter that runs directly in your browser.

## 🎮 Controls

* **Movement:** `W` `A` `S` `D`
* **Shooting:** `Left Click`
* **Debug / Test Mode:** `Tab`
